About me

I started modding Minecraft to change how ore generates, and ended up caring more about the mod loader than the mod.

That curiosity pulled me from Java into Python for tooling, C for the parts that need to be fast and explicit, and Rust when I want the compiler to catch my mistakes before the game does. Most of what I build exists to answer one question for myself: what is actually happening one layer down.

Currently pursuing a B.Tech in Computer Science Engineering.
